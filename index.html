PERF-1 SMK

PERF-1, the generative live-performance groovebox, on the M-Vave SMK-37 Pro: the same engine and pages as PERF-1 on the FM-1, with the SMK's 37 keys, 16 pads, faders, knobs and wheels. This page installs it over USB from Chrome or Edge on a computer.

The controls · Source and issues

A test build. It installs the way M-Vave's own updates do and leaves the keyboard's start-up code and its factory calibration alone, so M-Vave's firmware can always go back on (below, or with M-UPGRADE). Before the first install, download M-Vave's SMK-37 Pro firmware 016 from m-vave.com/download (PC Firmware) and keep it.

This build is for the SMK-37 Pro. An SMK-37 Elite or MKE-P37 needs its own build: the page refuses it and nothing is written. Ask for yours on the issues page.

Install

  1. Close M-UPGRADE and any music software that uses the keyboard's MIDI.
  2. Connect the SMK-37 Pro with a data USB cable, switch it on, and press Install. Allow MIDI when the browser asks.
  3. The keyboard restarts into its update mode, the bar fills, and it starts PERF-1 SMK (about a minute). Don't unplug it.

Live status (for a bug report)

How hard PERF-1 is working while it plays: CPU, the audio's late or lost blocks (xruns), the slowest block. Press Start, play for a few minutes, then Save CSV and attach the file to an issue.

Back to M-Vave's firmware

Puts M-Vave's own SMK-37 firmware back, from PERF-1 SMK, over the same cable. Choose the official file (SMK-37 Pro 016 from m-vave.com); the page checks it before anything is written. Pieces saved in PERF-1 SMK are lost. M-UPGRADE works for this too.
